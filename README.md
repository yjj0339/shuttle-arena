# SHUTTLE ARENA · 联机双人羽毛球

2.5D 立体视角的实时联机羽毛球，真实羽毛球空气动力学（阻力 ∝ v²，终端速度约 7.9 m/s）。

## 架构

- **入口页 `index.html`**：横屏全屏容器，加载运行中的游戏服务（联机需要长连接服务器，静态托管无法提供 WebSocket）。
- **`src/`**：完整前端源码（渲染、物理、输入、网络层），与服务端共用同一套物理内核。
- **服务端**：Node.js 原生 http + 手写 WebSocket（RFC 6455），服务器权威 60Hz 模拟、30Hz 快照广播、客户端插值。

## 玩法

- 左半屏按下唤出摇杆：左右＝沿球场跑动，上下＝前后走位
- 右下大键：按住蓄力，松手击球（蓄力＋击球高度决定球路）
- 右下小键：起跳（空中击球即为杀球）
- 七种球路：高远球 / 平抽 / 吊球 / 网前搓球 / 挑球 / 杀球 / 发球
